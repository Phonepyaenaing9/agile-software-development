# Project Charter – Game Currency Sale

## Project Name
Game Currency Sale System

## Project Purpose
This small project is a simple system for selling virtual game currency to players.

## Objectives
- Display available game currency packages.
- Allow a student/user to select a package.
- Calculate the total price.
- Record a simple sale.
- Show the sale information.

## Scope
The system will include:
- Game currency packages
- Customer name
- Package selection
- Quantity
- Total price
- Simple sale record

The project will not include real online payment, login, or connection to a real game.

## Technology
- Visual Studio
- C#
- .NET Console Application
- SQLite database design (SQL script included)

## Main Users
The main user is a customer who wants to buy game currency.

## Expected Result
A small working program that demonstrates basic programming, requirements, acceptance criteria, and database design.
