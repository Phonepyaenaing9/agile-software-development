# Game Currency Sale – Student Project

## How to Run in Visual Studio

1. Open Visual Studio.
2. Choose **Open a project or solution**.
3. Open `GameCurrencySale.csproj`.
4. Press **F5** or click **Start**.
5. Enter a customer name, choose a package, and enter quantity.

## Project Documents
- `01_Project_Charter.md` – Project Charter
- `02_Requirements_Specification.md` – Requirements Specification
- `03_Acceptance_Criteria.md` – Acceptance Criteria
- `04_Database_Design.md` – Database Design
- `05_database.sql` – SQL database script
- `Program.cs` – C# program
- `GameCurrencySale.csproj` – Visual Studio/.NET project file

## Note
This is a small educational project. The currency and prices are fictional examples. It does not process real payments or connect to a real game.
