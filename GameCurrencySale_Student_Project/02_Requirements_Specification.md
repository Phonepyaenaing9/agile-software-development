# Requirements Specification – Game Currency Sale

## Functional Requirements

**FR1 – View Packages**  
The system shall display available game currency packages.

**FR2 – Select Package**  
The user shall be able to choose a package by entering its number.

**FR3 – Enter Quantity**  
The user shall enter the number of packages to buy.

**FR4 – Calculate Total**  
The system shall calculate total price using:
`Total = Package Price × Quantity`

**FR5 – Customer Name**  
The system shall ask for the customer's name.

**FR6 – Display Sale**  
The system shall display the customer name, package, quantity, and total price.

## Non-Functional Requirements

- The program should be easy for a student to understand.
- Input should be checked for invalid numbers.
- The program should run in Visual Studio.
- The interface should be simple and text-based.
- No real money or real game account should be connected.

## Assumptions
Prices are sample prices for an assignment and are not real game prices.
